Comparador de IA

Compara modelos y prompts de IA generativa sobre un mismo set de tareas, con criterios medibles, y genera un reporte con ranking y recomendación.

PythonAPI de ClaudeCSVpytest
Cómo funciona
  1. Lee tareas de un JSON: prompt, conceptos clave y límite de palabras.
  2. Envía cada tarea a cada configuración (modelo + prompt de sistema).
  3. Puntúa cobertura de conceptos, extensión y tiempo de respuesta.
  4. Exporta un reporte en Markdown y los datos en CSV.

API de Integración de Cobranzas

Integra el sistema de gestión de una empresa con las notificaciones de pago de un banco y concilia facturas automáticamente.

PythonFastAPISQLSwaggerpytest
Cómo funciona

  2. El banco notifica cada pago recibido.
  3. La API valida factura, monto y que el pago no esté repetido.
